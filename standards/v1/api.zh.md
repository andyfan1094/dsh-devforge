# API 服务规范（v1）

tags: api, service, 后端

## 1. 路由与分层

- 路由只做参数校验与调度，业务逻辑进 service 层，数据访问进 repository/dao 层。
- 每个接口必须定义：方法、路径、入参 schema、出参 schema、错误码。

## 2. 安全边界

- 管理类接口必须加来源校验（loopback/鉴权中间件），默认拒绝外网。
- SQL 一律参数化；禁止字符串拼接查询。
- 文件上传：校验类型/大小/重命名落盘，禁止原始文件名直接拼路径。

## 3. 可观测

- 关键流程打结构化日志（时间/动作/耗时/结果）；异常日志带堆栈。
- 健康检查端点 /healthz 必须提供。

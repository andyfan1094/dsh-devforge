# Web 服务脚手架规范（v1）

tags: service, 脚手架, web

## 1. 必备结构

生成的 Web 服务必须包含：

- 入口文件（含中文注释说明启动流程与端口）
- config（环境变量读取与默认值，含中文注释）
- routes → service → repository 三层骨架
- 统一错误处理中间件（兜底 500 返回可读信息，不泄内部细节）
- /healthz 健康检查
- README.md（启动/验证/已知限制）

## 2. 生成流程要求

1. 先输出实施清单（文件树 + 每个文件一句话职责），再写代码；
2. 每个文件头部写"入口说明 + 关键流程"中文注释块；
3. 完成后本地启动自测一次（能起服务、/healthz 200）再交付。

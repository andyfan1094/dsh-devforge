# 创造模式 250k 压缩预设兼容补丁

## 用途与边界

当前 `@deepseek-ai/dsh-tool-cordis` 0.1.2-rc.1 在每份创造模式加载时向进程共享注册表写入固定的四个 Host 检查接口 ID，复制预设与原预设并存时会重复注册。本工具只为用户预设生成独立模块，将注册 ID 加上 `<预设ID>/` 前缀。模型工具名称、参数、提示词、作用域、动态插件执行和 Client 查询通道均保留；不修改已安装 DSH 文件，不重启生产。

源码入口为 `scripts/cordis-preset-compat.mjs`。它固定校验已审查的版本、完整源码 SHA-256、注册边界和三个导入位置。上游版本或源码变化时拒绝生成。核心依赖解析到上游包实际使用的同一份模块；生成物携带许可证、来源和哈希记录。它是本地兼容方案，不是官方配置项。

## 生成与启用

1. 使用预设服务的 `copy()` 或设置中的“复制”创建 `cordis-250k` 用户预设，源预设选 `cordis`。禁止改写内置预设。
2. 运行以下命令，将占位参数换成当前安装与用户预设的真实绝对路径：

```bash
node scripts/cordis-preset-compat.mjs <上游dsh-tool-cordis/package.json> <用户根/.agent-presets/cordis-250k> cordis-250k
```

3. 将副本的 `tool-cordis` 行 `name` 改为 `./cordis-tools.compat.mjs`。在副本的 `compaction-basic` 行配置 `thresholdRatio: 0.25`。
4. 模型窗口为 1,000,000 tokens 时，阈值为 250,000 tokens；默认近期保留量为 160,000 tokens。其他窗口按 25% 换算，不能称为所有模型固定 250k。压缩在请求步骤边界检查，实际触发可能略高。
5. 在独立 HOME 的暂存实例验证预设加载和界面，保持飞书桥与桌面宠物关闭；不得使用生产 HOME。暂存实例已占用时复用经核验的隔离实例，不关停他人实例。
6. 调用 `agentPresets.standingKeyFor('cordis-250k')` 验证通过后，再通过 `settings.update('agent-presets', { default: 'cordis-250k' })` 切换默认；旧会话不会迁移。

## 验证

```bash
DSH_CORDIS_PACKAGE=<上游dsh-tool-cordis/package.json> node --test scripts/cordis-preset-compat.test.mjs
```

聚焦验证原生与副本共存、反序挂载、仅副本加载、精确 Host 查询、Client 透传、工具作用域、独立卸载、动态工具保留及错误输入拒绝。真实预设挂载另由隔离宿主完成。无需向模型发送 250k 文本制造付费请求；阈值解析和加载验证不能冒充一次真实长会话压缩验收。

## 维护和回退

设置中的默认预设改回 `cordis` 即可使后续新会话恢复原策略。不要在仍有会话使用副本时删除其文件。升级 DSH 后应从新版本重新复制预设、审查并更新生成器的版本和哈希，再重新测试；生成物中的 API 目录不会自动升级。再次复制这个副本时必须给新预设重新生成不同前缀，直接复制同一个兼容模块仍会撞名。

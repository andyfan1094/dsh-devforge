# 控制台与仪表盘布局 craft rules

本文件决定控制台、管理后台、数据看板这类「多任务、数据密集、每日长时间驻留」界面的结构与信息架构：什么进壳层、什么留在页面、一屏放多少、每个数字怎么标、每张图怎么选。它不决定品牌视觉——颜色、字体、圆角由当前 `DESIGN.md` 与 `tokens.css` 决定。渲染级规则也不在这里：五态齐备与加载阈值见 `state-coverage.md`，焦点环、对比度、可点面积见 `accessibility-baseline.md`，动效时长见 `animation-discipline.md`，卡片内排版层级见 `typography-hierarchy.md`。

判定原则：每条都写成可判定的形式——给数字，或给「A 则 X，B 则 Y」的二选一判据。标注**经验区间**的数字来自本文件的工程收敛，不来自被引用的设计系统；其余数值可回溯到文末来源。

> 提炼自 IBM Carbon Design System（UI shell、global header、data table、spacing、dashboards、axes and labels、empty states、filtering）、GitHub Primer（layout、page header、data visualization、loading、degraded experiences、navigation）、Atlassian Design System（spacing、navigation system layout）、Ant Design（布局、导航、数据展示三项规范）、Nielsen Norman Group（仪表盘与复杂应用可用性、响应时间三阈值）。

## 一、导航壳层：三层职责，各只做一件事

控制台的导航不是「一个侧栏」，而是三层互不越权的容器。判据：这个入口全站任何页面都出现吗？是→全局；只在本产品内出现吗？是→产品级；只在当前对象内出现吗？是→页面级。

| 层级 | 常驻位置 | 承载 | 禁止承载 |
|---|---|---|---|
| 全局 | 顶部壳层，永久可见 | 产品切换、账号、通知、系统设置、登录态/模式 | 具体业务页面的跳转 |
| 产品级 | 侧栏或壳层内的产品导航 | 本产品功能区（对象列表、任务、配置分组） | 用户创建的无上界内容 |
| 页面级 | 面包屑、页内 tabs、锚点 | 当前对象/当前页内的视图切换与回退 | 跨对象跳转 |

- 全局区里**系统级入口右对齐、产品级入口左对齐**（Carbon）；窄视口放不下时分别落右侧与左侧面板，不截断、不隐藏。工具类图标不做直接跳转，点开是面板或浮层。
- 侧栏必须支持「折叠为图标条 / 浮层」两种降级形态，且功能不减。**经验区间**：视口 ≥1024px 常驻内联，小于该值折叠为浮层（Atlassian 导航系统 1024–1439px 为内联，320–1023px 为浮层）。
- 侧栏**禁止放用户创建且无上界的内容**（项目名、标签、文件列表）。Carbon：壳层导航项过多时可用性下降，无上界内容走下钻模式。
- 导航顺序按**用户目标分组**（Carbon：目标分组 > 最近使用 > 字母序）。字母序在用户想的是同义词时失效，最近使用会破坏逻辑分组，两者都不宜作主排序。
- **把筛选与下钻状态写进 URL**（Carbon），否则用户从下钻返回时会丢掉筛选条件。

## 二、导航项数量、分组与层级上限

| 容器 | 上限 | 超出时怎么办 | 来源 |
|---|---|---|---|
| 顶部一级导航 | 2–7 项；标题 4–15 字符（中文 2–6 字） | 拆分产品，或改侧栏 | Ant Design 导航 |
| 侧栏一级项 | 无硬上限，但必须分组 | 分组 + 分区标题 + 可滚动；**经验区间**：首屏可见 ≤12 项 | Ant Design 导航 |
| 侧栏二级项 | 超过 5 个必须用左侧面板 | 少于 5 个时顶栏下拉即可 | Carbon left panel |
| 导航层级 | 最多 2 层 | 第 3 层放页内 tabs | Carbon（左面板不支持三层） |
| 面包屑 | 显示 ≤3 级，最多 5 级 | 中间层级折叠为省略号 | Ant Design 导航 |
| 页内 tabs | 标题 2–6 个中文字 | 分类过多改竖排 tabs（不限数量） | Ant Design 导航 |

1. **导航只表达位置，不表达状态**。角标只用于「需要处理的数量」，不用颜色单独表达。
2. **不能有死入口**：无权限或无数据的入口要么不渲染，要么禁用并附一行原因，不要让点击无反应。
3. **DOM 顺序 = 视觉顺序**（WCAG 2.1 技术 C27，Carbon 引用）；用 CSS 改视觉排序会让读屏层级与视觉层级不一致。
4. **skip link 放在壳层第一个可聚焦位置**；主导航、主内容、搜索各有 landmark 标签，多个导航区必须有唯一标签（Carbon）。

## 三、页面骨架与页面头部

页面头部只有一个合法编排顺序，自上而下：父级返回链接（**只在窄视口出现**，Primer `ParentLink` 在常规与宽视口默认隐藏）→ 上下文行（面包屑或对象元信息，深下钻页面面包屑一律放**标题上方**，Carbon）→ 标题区（标题 + 一行描述 + 主操作在右）→ 页内导航（tabs，紧贴头部下方；有页内导航时不渲染头部下边框，避免两条线，Primer）。

- 同一页面**主按钮恰好 1 个**；次级操作走次级按钮或溢出菜单。
- 标题区不放统计数字：指标属于内容区，混进头部会让「这是什么页面」与「现在什么情况」互相干扰。
- 描述行是**口径说明位**：写数据范围（如「近 7 天，不含测试账号」），不写营销句。

## 四、主内容宽度与分栏取舍

- **文本型内容必须限宽**：Primer 页面容器上限 `xlarge` = 1280px（含 24px 内边距，有效宽约 1232px）；本文件同此判据，正文行宽控制在 60–80 个西文字符以内。
- **表格型内容可以突破限宽**：页面上最大的宽度优先给表——宽表允许全宽并横向滚动，但必须固定首列（标识列）与表头，避免截断与失去参照。
- 页面按是否有侧栏三分（Primer）：**Full page**（居中，无侧栏）、**Split page**（左导航/列表 + 右详情，各自可滚）、**Interstitial**（居中卡片，用于确认与单步任务）。判据：需在同类对象间频繁切换→Split；一次只处理一个对象→Full/Interstitial。
- 右侧检查器只在「选中对象↔改属性」占 80% 时间时使用，否则拆独立页面，避免主区被永久压缩。检查器宽度**经验区间** 320–400px，低于 320px 表单标签开始折行。
- 栅格：24 列 + 8px 基数，gutter 固定、列宽缩放（Ant Design）；1440px 为设计基准画板，同时验收 1920 / 1440 / 1366。
- 窄视口必须**降级为多视图**（拆视图、堆叠或底部面板，Primer），不允许横向被压扁的三列。

## 五、指标卡纪律

**一张卡只承载一个指标 + 一个对比基准。** 同一张卡出现两个不同量纲的主数字即不合格。合格卡片必须齐备七项，缺一不合格：

| 项 | 要求 | 反例 |
|---|---|---|
| 指标名 | 名词或名词短语，不写句子 | 「快来提升你的转化」 |
| 数值 | 主角，字号 ≥ 标签的 2 倍，等宽数字（`tabular-nums`） | 数值与标签同号 |
| 单位 | 紧随数值、小一号字；百分比与计数分开写 | 「12」不知是次还是万 |
| 时间范围 | 明确口径：今日 / 近 7 天 / 本月 | 无范围 |
| 对比基准 | 环比、同比或目标值，三选一且写明基准名 | 只有孤立的上升箭头 |
| 出处/口径 | 可点到口径说明或数据来源 | 数字无从查证 |
| 更新时间 | 卡级时间戳（见第十节） | 全页只有一个时间 |

- **禁止无出处数字。** 无真实数据按序降级：真值 0 → 显示 0；无数据 → 显示「—」（Ant Design：空单元格用 `-`）；接口失败 → 错误态 + 重试。**不得**显示 0 或伪造趋势。
- **单位与精度**（本文件规则，取舍区间为**经验区间**）：计数取整数带千分位，≥10 万用「万」、≥1 亿用「亿」，缩写保留 1 位小数；金额元与万元保留 2 位且不省币种符号；百分比 1 位小数，小于 0.1% 写「<0.1%」；比率 2 位小数且不用百分比；时长按量级选 ms/s/min。同一指标精度全页一致。
- 上升下降本身不含语义：必须配目标线或好坏判定（「对比上周 +12%」＋目标值），只有红绿箭头无基准时判为不可判定。
- 大数字 vs 小图表：单点状态用大数字 + 单位 + 对比；只问方向用大数字 + 迷你趋势线（无坐标轴）；问何时变化用完整折线/柱图；问构成用堆叠条或条形，不用缩小版饼图（面积/角度难比较，NN/g）。

## 六、数据密度与间距 token

数据表行高用固定五档（Carbon data table）：

| 档位 | 行高 | 适用 |
|---|---|---|
| xs | 24px | 极限密集，一屏内做多列对比 |
| sm | 32px | 紧凑界面，仍要可读可点 |
| md | 40px | **默认档**，无特殊要求时用它 |
| lg | 48px | 强调、更易点击的宽松布局 |
| xl | 64px | 单元格内有两行内容时 |

- **同高度对齐是硬规则**：表头行高等于数据行高（Carbon）；工具栏与分页器按档位与行高配对，高工具栏只配 lg 与 xl 行高（Carbon）。混用高度判为不合格。
- 间距走 token 不写魔法值：2 / 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48px（Carbon spacing，允许断点处整级跳档）；Atlassian 同构体系以 8px 为基数（`space.100`=8px、`space.200`=16px，最大 80px），并分三档用途——0–8px 用于组件内小间隙（图标与文字、输入框内边距、表单元格内边距），12–24px 用于卡片内元素与卡片间距，32–80px 用于区块之间。
- 落位规则：卡片内边距 ≥16px；卡片之间 16–24px；区块之间 32–48px；筛选栏与页头之间 24px。
- **留白不是浪费**：Carbon 引用 Human Factors International 的数据，留白使理解度提升接近 20%。密度只能靠减少装饰与压缩重复结构取得，不能靠压缩元素间距。
- **允许紧凑模式的三个前提必须同时满足**：① 用户是每日使用的高频操作者；② 主任务是对比或扫描而非阅读；③ 列宽稳定且数字对齐。缺一即回默认档 40px。
- 数字右对齐或按小数点对齐，文本左对齐，表头与列内容同对齐。一个视图内不要混用 24px 行高表格与大留白卡片两种密度节奏。

## 七、图表选型

先判数据形态，再选图：

| 数据形态 | 首选 | 上限 | 禁止 |
|---|---|---|---|
| 时间序列 | 折线图 | ≤5 条线，超出拆子图 | 双 Y 轴叠不同量纲曲线 |
| 累积构成随时间 | 堆叠面积图 | 建议 ≤3 条，最多 5 条 | 用堆叠面积比较单条精确值 |
| 类别排名 | 横向条形图 | ≤10 条 | 3D 条形、用颜色表达排名 |
| 少量类别对比 | 柱状图 | ≤10 柱 | 柱顶重复标全量数字 |
| 分组对比 | 分组柱 | 每组 ≤4 类、≤6 组 | 超限仍用分组柱 |
| 部分与整体 | 堆叠条 / 饼图 | 饼图 ≤5 片 | 3D 饼图、以面积角度做精确比较 |
| 分布 | 直方图、箱线图、散点 | 按数据量抽样 | 用折线表示无序分类 |
| 相关性 | 散点图 | 过密时改密度/分箱 | 强加趋势线而不标拟合优度 |

- NN/g 判据：仪表盘是**一眼可读**的，不是探索工具；量化关系优先用长度与二维位置表达，人对面积与角度的比较精度差，饼图、指针仪表、雷达图只适合粗看。
- 单点数据不配坐标轴：一根柱/一条线的「图表」应改回指标卡。
- **颜色不得是唯一区分手段**：多系列同时用线型（首条实线，其余虚线/点线）、点形状（首条圆形）或直接标注（Primer）；相邻色对比 ≥3:1。同一看板内图表布局、间距、图例位置一致，且不在图表之间切换计量单位（Carbon）。
- 联动：一个图表被筛选或缩放时，同源数据的其余图表同步更新（Carbon linked charts）。

## 八、坐标轴、图例与标注

- **默认给所有轴加标签**，轴标签要能脱离图表标题独立理解（读屏用户不应需要记住标题）；仅当轴内容不言自明（如日期轴）可省略（Primer）。
- 对比度：轴标签 ≥4.5:1，轴线 ≥3:1，轴线用边框 token；折线与面积的数据线统一 2px 线宽（Primer）。
- **柱状图与面积图必须从 0 起**；折线与散点允许裁掉空白区间，但必须画出显式的轴断裂标记（Carbon 要求轴断可见），不许静默截断。
- **缺失数据不许插值**：缺口用纹理或不连续段表示（Carbon），不连成平滑曲线、不填 0。
- 时间轴跨日/跨月/跨年的第一个刻度加粗为「界标标签」；刻度格式全页统一，不混用相对与绝对时间（Carbon）。
- 图例：只有 1 个系列时省图例、用标题描述该系列；≥2 个系列必须有图例或直接标注（Primer）。
- 注解只标趋势、均值、峰谷，不得遮挡数据，每图 ≤2 条，超出换表达方式（Carbon）。

## 九、筛选与时间范围

- **全局与局部筛选的边界**：影响页面上全部卡片与图表的条件（时间范围、环境、租户）放页面级筛选栏；只影响单个卡片或表格的放该组件工具栏。同一条件不得两处同时出现。
- 控件选择：≤5 项用分段控件或复选组；>5 项用带搜索的多选面板；分类维度多时按类别分组并支持批量应用。
- **必须能看出「已筛选」**：已应用条件以 chip 常驻显示，并提供按类别清除、全部清除、已应用计数。**禁止**应用筛选后收起筛选控件。
- 「全选」与「未选」必须是两个视觉状态，不可都渲染为空；默认状态要显式定义，默认全选就不能显示成「0 项已选」。
- 时间范围控件显示当前值本身（「近 7 天」或「2026-10-01 ~ 2026-10-14」），不只显示日历图标；相对范围随今天滚动、绝对范围固定，默认范围写在页面上。
- **筛选后的空态要能归因**：明说是「当前筛选条件下没有数据」，给一键清除，其余卡片正常渲染；禁止显示成产品空账号态。

## 十、刷新、实时与时间戳

刷新频率不得高于数据产生频率，否则是在制造假实时：

| 数据性质 | 自动刷新 | 手动刷新 | 备注 |
|---|---|---|---|
| 秒级监控（告警、队列、在线数） | 5–15s | 提供 | 标签页不可见时降频或暂停 |
| 运营看板（订单、转化） | 1–5min | 提供 | 默认档 |
| 报表类（周月汇总） | 15–60min 或不自动 | 必须提供 | 手动刷新即够 |
| 日汇总 | 不自动刷新 | 提供 | 附数据截止日 |

（上表节奏为**经验区间**；响应时间阈值有据：0.1s 视为即时、1s 内不打断思路、10s 是注意力上限，NN/g。Primer：加载 <1s 不显示任何加载态，1–3s 用不确定态，约 ≥3s 才值得用确定态。）

- 时间戳固定在页面头部右侧或内容区工具栏右端，全页共用；卡级时间与页面级不一致时卡片须自报时间。
- 格式为**相对时间 + 绝对时间**（「3 分钟前」，`title`/tooltip 给「2026-10-14 11:03」）；相对时间在停留期间需重算（Primer 的 RelativeTime 即此类组件）。
- **延迟要诚实**：同时给「数据时间（事件时间）」与「抓取时间」；数据时间落后当前时间超过刷新周期 2 倍时，把时间戳换成显式延迟状态（「数据延迟约 12 分钟」），不继续显示「刚刚更新」。
- 自动刷新必须**保留滚动位置与筛选状态**，不整页闪烁；用户悬停、展开行、编辑内联字段或打开下拉时暂停刷新并提示。
- 手动刷新按钮进入禁用/加载态并防重复提交，只更新数据不重建整页；动效尊重 `prefers-reduced-motion`（另见 `animation-discipline.md`）。

## 十一、首屏、加载与部分失败

- **骨架与最终布局同形**，逐卡独立加载；大块内容用骨架而不是转圈（Primer：用内容的模糊替身替代加载区，能让人感觉更快），禁止一条灰条代替整页。
- **局部失败不得拖垮整页**：先判定该数据是主体验还是次体验（Primer）——页面没有它无意义则显示错误页；只是增强则保留页面，该区域替换为「暂时不可用」+ 重试（带错误 ID）。
- 数据不可用而用户此前确实创建过数据时，**禁止渲染通用空态**（Primer：用户会误以为数据丢失）；应说明「暂时无法读取」，或整块连同标题一起移除。
- 失败时**不留不可用的交互控件**（Primer）：要么隐藏，要么禁用并说明原因。全局故障用导航上方的 warning 横幅告知并给状态页链接。
- 首屏并发请求**经验区间** ≤8 个；先渲染壳层与骨架，首屏之外的图表延后。连续 3 次失败后把「重试」换成「联系支持」（同 `state-coverage.md` 的重试纪律）。

## 十二、空账号：有产品、无数据

空态按触发原因分三类；控制台的首屏只有一次机会，先分类再决定形态：

| 空态类型 | 触发 | 必须包含 | 禁止 |
|---|---|---|---|
| 无数据（新账号） | 刚进入，产品无数据 | 「为什么空」+ 数据从哪来 + 恰好 1 个主 CTA | 每张卡各放一个主按钮 |
| 无结果（查询/筛选后） | 筛选或搜索无命中 | 回显条件 + 清除入口 | 与「无数据」共用文案 |
| 错误管理（不可用） | 数据读取失败 | 失败原因 + 重试 | 伪装成空态 |

- **首屏空账号用页面级空态替代满屏空卡片**：不要渲染 6 张写「—」的卡片 + 6 个相同的「去创建」；改为 1 个页面级空态（说明 + 1 个主 CTA + 可选文档链接），其余卡片收起。
- 同页多个空态时**只有最重要的一个给主按钮**，其余用三级按钮或链接。
- CTA 指向的动作必须真的能做成那件事（接入第一个数据源 / 创建第一个对象 / 导入一行数据）；空态不是错误、错误不是空态，文案模板不得复用（同 `state-coverage.md`）。

## 十三、常见失败模式（逐条判定）

- 侧栏塞入用户创建、数量无上界的内容 → 走下钻。
- 导航出现第三层（侧栏套侧栏）→ 改页内 tabs。
- 页面头部有两个及以上主按钮。
- 面包屑超过 3 级，或被当作页面标题。
- 指标卡缺时间范围或缺对比基准。
- 指标卡内出现两个量纲的主数字。
- 无数据或接口失败时显示 0。
- 同页同指标精度不一致（12.3% 与 12.34% 并存）。
- 表头行高与数据行高不一致，或分页器高度不随行高。
- 同屏混用 24px 行高表格与大留白卡片两种节奏。
- 柱状图起点不是 0 且无断轴标记；折线图静默截断 Y 轴；给缺失数据插值或把缺口填 0。
- 双 Y 轴叠两条不同量纲曲线；3D 饼图；用面积角度做精确比较。
- 只用颜色区分系列；多系列无图例也无直接标注。
- 图表缺轴标签，或轴标签脱离标题无法理解。
- 应用筛选后收起筛选控件、看不出已应用条件，或把筛选导致的空显示成「还没有数据」。
- 自动刷新无时间戳，或时间戳只有相对没有绝对，无法互查。
- 刷新频率高于数据产生频率，或自动刷新把滚动位置、筛选、展开状态重置。
- 单卡接口失败导致整页报错，或失败卡片渲染成空态。
- 首屏空账号渲染满屏「—」卡片并重复 CTA。

## 十四、交付前自检清单（可打钩）

- [ ] 导航三层职责无越权：全局/产品级/页面级各只做一件事
- [ ] 顶栏一级 2–7 项；侧栏有分组；不存在第三层导航
- [ ] 侧栏不含无上界内容；宽视口常驻、窄视口折叠且功能不减
- [ ] 壳层首个可聚焦元素为 skip link；导航与主内容各有 landmark 标签
- [ ] DOM 顺序与视觉顺序一致（含窄视口重排）
- [ ] 头部顺序为：父级链接（窄视口）→ 上下文/面包屑 → 标题+描述+主操作 → 页内导航
- [ ] 每页主按钮恰好 1 个；口径说明写在描述行
- [ ] 文本限宽（约 60–80 字符/行）；宽表可突破限宽且首列与表头固定
- [ ] 桌面 1920/1440/1366 三档与窄视口降级形态都已截图看过
- [ ] 每张指标卡齐备七项（名、值、单位、范围、基准、出处、时间）
- [ ] 无数据显示「—」，失败显示错误态，无任何无出处数字
- [ ] 首屏指标卡 ≤6 张，按 F 型重要性排序
- [ ] 表格行高取自 24/32/40/48/64，表头、工具栏、分页器与行高一致
- [ ] 间距全走 token；卡片内边距 ≥16px，区块间距 32–48px
- [ ] 每个图表可由「数据形态→图形」表推出，系列数在上限内
- [ ] 柱/面积从 0 起；折线截断处有断轴；缺失数据未插值
- [ ] 轴标签齐备且可独立理解（轴标签 4.5:1、轴 3:1），线宽 2px；多系列有图例或直接标注，颜色不是唯一区分
- [ ] 筛选区分全局与局部且无重复条件，已应用条件常驻可清除
- [ ] 时间范围显示当前值，默认范围写在页面上
- [ ] 筛选后空态可归因、可一键清除，其余卡片不受影响
- [ ] 刷新节奏与数据产生频率匹配，标签页不可见时降频或暂停
- [ ] 时间戳为相对 + 绝对时间，延迟超阈值时显式标注；自动刷新不重置滚动/筛选/展开
- [ ] 骨架与最终布局同形、逐卡独立加载；单卡失败只影响该卡，有重试与错误 ID
- [ ] 空账号为页面级空态：说明 + 恰好 1 个主 CTA
- [ ] 空态/错误态/加载态三套文案不复用（对照 `state-coverage.md` 五态）

# 界面文案去 AI 味

> 改写自 MohamedAbdallah-14/unslop 的 `anti-aiisms.md`（MIT）—— 原库处理的是**散文**去 AI 味，此处**只保留能迁移到界面与产品文案的部分，并改写为 UI 语境**。检测器规避、stylometry、突发度那类与产品文案无关的内容已剔除。
> 用法：写界面文案时对照；交付前把按钮、提示、空状态、错误信息过一遍。

## 一级：出现即删

**空洞形容词**：强大、无缝、极致、卓越、领先、赋能、革命性、颠覆性、全方位、一站式、深度、智能
**动词虚胖**：赋能、助力、打造、构建（当"做"就够时）、释放潜力、开启旅程、解锁
**英文对应**：seamless / robust / leverage / empower / elevate / unleash / revolutionize / cutting-edge / state-of-the-art / game-changing / unparalleled
**开场套话**："在当今快速发展的时代"、"在 XX 的浪潮中"、"让我们一起…"、"值得注意的是"、"总而言之"、"综上所述"、"值得一提的是"
**谄媚**："很好的问题！"、"感谢您的提问"、"希望这能帮到您"、"如有任何疑问随时联系"

## 二级：组合出现才删

- 对偶句式"不只是 X，而是 Y"（以及"It's not just X, it's Y"）
- 三连排比：X、Y、Z 三个同义或近义形容词并列
- 抽象名词堆叠：一句里出现 ≥3 个「洞察 / 方案 / 策略 / 机会 / 能力 / 体验 / 旅程 / 视角 / 考量」
- 列表里每一项都以同一词形开头（"强大的…强大的…强大的…"）
- 每段都以过渡副词起头

## 三级：过量才删

- 程度副词（非常、真的、相当、十分、极其、极其）：每 200 字超过 3 个
- 副词开头（重要地、有趣地、显著地、本质上、根本地）
- 破折号：每 200 字超过 1 个

## 改写对照（好文案长什么样）

| 场景 | AI 味写法 | 改写 |
| --- | --- | --- |
| 主按钮 | 立即开启您的专属旅程 | 开始记录 |
| 空状态 | 暂无数据，快来创建您的第一个任务吧！ | 还没有记录。添加第一条 |
| 成功提示 | 操作已成功完成！ | 已保存 |
| 错误提示 | 哎呀，出了点小问题，请稍后重试 | 保存失败：连不上服务器。重试 |
| 营销标题 | 赋能企业数字化转型的一站式解决方案 | 把订单和库存放进同一张表 |
| 功能描述 | 强大的智能分析能力 | 每天早上 8 点，把昨天的销量发到群里 |
| 引导语 | 让我们一起来探索这个功能吧 | 点右上角新建 |
| 加载态 | 正在努力为您加载中，请稍候… | 加载中… |
| 订阅提示 | 解锁无限可能，畅享极致体验 | 每月 ¥29，无限次导出 |

## 判据

把截图给一个外人看：**对方能说出"这是哪个产品"吗？**

- 能 → 文案有产品味（出现了只有做过这个产品的人才会写的话：真实的单位、真实的流程名、真实的边界条件）
- 不能 → 你交付的是一套模板，回上表重写

## 与反 AI 味清单的关系

视觉层面的 AI 味见 `craft/anti-slop-unified.md`（禁紫蓝渐变、禁 emoji 当图标等）；本节只管**文字**。两者在"编造指标"上重叠：`99.9% 可用性`、`10× 更快`、`+47% 转化` 这类没有真实来源的数字，视觉与文案都算违规。

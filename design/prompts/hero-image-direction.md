# 主视觉生图提示词

> **用途**：为落地页首屏、文章头图、演示稿封面生成主视觉。
> 生图最常见的两个失败：① 主体挤满画面，没地方压标题；② 风格撞上"AI 味"（紫蓝渐变、玻璃拟物堆砌、无意义的发光球体）。
> **用法**：按下面骨架逐格填写，再用 `generate_image` 出图，出来后**一定要看图**再决定留用。

## 提示词骨架

```text
主体：<画什么，一个明确的主体，不要并列两三个>。
场景：<它处在什么环境里，环境要能解释这个主体的用途>。
构图：<主体在画面的哪个位置；单点透视/平铺/俯拍等；画面留出 <左/右/上>侧 <比例> 的干净区域用于压文字>。
光线：<光源方向与性质：侧逆光 / 顶部柔光 / 阴天散射；明暗对比强或弱>。
材质与色彩：<两到三色的色彩关系 + 一个强调色；材质写具体：磨砂铝、粗纹纸、哑光涂料>。
镜头与视角：<焦距观感：35mm 环境感 / 85mm 压缩感；高度：与主体齐平 / 略高俯视>。
风格基准：<写"像什么"而不是"好不好看"：工业产品摄影 / 建筑图纸 / 黑白纪实>。
画幅：<如 16:9 用于首屏，4:5 用于社媒，1:1 用于头像位>。
负面：塑料感、过度光晕、紫蓝渐变、无意义漂浮几何体、文字水印、多余的手指与肢体、畸变透视、JPG 噪点。
```

## 尺寸与用途对照

| 用途 | 建议比例 | 说明 |
| --- | --- | --- |
| 落地页首屏 | 16:9 或 21:9 | 上方或侧方需留出标题安全区 |
| 卡片配图 | 4:3 或 3:2 | 缩到 320px 宽仍需主体可辨 |
| 社媒竖版 | 4:5 或 9:16 | 重要主体避开上下 15% 的裁切区 |
| 图标位 | 1:1 | 主体居中，四周留白 ≥ 15% |

## 出图后的三步验收

1. **缩略图测试**：缩到 200px 宽还能认出主体，否则构图太散。
2. **压字测试**：把真实标题按目标字号压上去，读得清才算有安全区；读不清就重出，不要靠加蒙版硬救。
3. **撞风格检查**：画面里有没有紫蓝渐变、无意义光球、塑料光泽？中了就改提示词的"材质与色彩"与"负面"两行重来。

## 禁止事项

- 不要用提示词生成带文字的图（文字必然错字，标题一律用 HTML 排版）。
- 不要把两张不同风格需求的图塞进同一次生成，风格会互相污染。
- 不要用 emoji 或"✨高级感✨"这类词描述风格，模型无法据此收敛。
